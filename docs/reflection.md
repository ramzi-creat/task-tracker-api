# Reflection

Throughout this AI-assisted feature extension sprint, I used AI tools primarily to plan data validation schemas, structure Pydantic models for dates and tags, and draft frontend template updates. One major moment AI helped was quickly generating the correct Pydantic date validation syntax, which saved considerable time on debugging 422 error codes. Conversely, a moment AI slowed me down was when it suggested an overly complex database relation for tags, which I deliberately rejected in favor of a simpler string-list representation to keep the scope aligned with the project constraints. My own critical review changed the result by ensuring we avoided unnecessary microservices or heavy packages, keeping the Task Tracker lightweight, fast, and fully compliant with the course rubric.
